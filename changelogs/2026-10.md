# October 2026

The first big update in three years. It covers the bot, the [dashboard](../website/dashboard/README.md) and the translation API. Limits are given as **Free / Premium**, see [Premium](../premium/premium.md).

## New features

### Translation groups
* `/group create`, `/group delete`, `/group set-channel`, `/group remove-channel`, `/group settings` and `/group list` link several channels, **each with its own language**. A message written in one channel is translated into the language of every other channel of the group (one translation per language).
* A channel can be **paused** without being removed from the group.
* The lifetime of translations is configurable, from **5 seconds to 24 hours** (`/group settings`, and the dashboard).
* Limits: **1 group of 3 channels** (Free) / **5 groups of 5 channels** (Premium).
* See [Translation groups](../commands/groups.md) and the dashboard page [Translation Groups](../website/dashboard/translation-groups.md).

### Speech to text
* `/transcribe start` writes live what is said in a voice channel. The language is detected automatically, in every language.
* `/transcribe auto enable` / `disable`: the bot joins and transcribes by itself when someone joins a voice channel.
* Output styles: webhook (default), message or embed. A voice channel can have several destinations (up to 3 with Premium, 1 otherwise), including forums and the chat of the voice channel.
* Sentences are sent at the natural pauses of the speaker, while the person is still talking.
* **Live translation** of the transcription is a Premium feature.
* Transcription time per server: **30 minutes per day** (Free) / **3 hours per day** (Premium), from midnight UTC. The time of all sessions adds up. See [Daily limits](../audio/limits.md).
* Settings changed on the dashboard apply to the running session. The bot announces the start of a transcription in the voice channel.
* Free servers need a [top.gg](https://top.gg) vote, Premium servers do not. See [Voice](../audio/voice.md).

### Text to speech
* `/tts say` reads a text aloud in your voice channel, in **52 languages**, with a queue. The language is detected automatically or chosen.
* `/tts-channel set|remove|list` reads every message of a text channel aloud: **5 channels** (Free) / **25 channels** (Premium).
* `/tts stop` stops the speech and empties the queue. (In this update it was `/tts-stop`; see [Unreleased](unreleased.md).)
* The bot leaves the voice channel **30 seconds after the last person left**.
* An adaptive anti-spam keeps the channel readable during message bursts.
* Links, mentions, code and markdown are cleaned before reading.

### FAQ and `/ask`
* `/faq add`, `/faq list` and `/faq remove` build a FAQ for your server. `/ask` answers in the language of the member, and the bot can **answer automatically** in the channels linked to a FAQ group.
* Only answers written by your moderators are sent. They are never generated.
* Limits per group: **5 entries** (Free) / **150 entries** (Premium). The automatic reply uses a confidence threshold (85 % by default, between 80 % and 95 %) and a *Not helpful* button.
* See [FAQ and /ask](../qa/faq.md).

### Flag shortcuts
* `/flags set` adds **up to 5 flags** under every message of a channel: one click on a flag translates the message. `/flags clear` removes them.
* **Flags that did nothing before now work**: Hebrew, Bengali, Tswana, Wales and Scotland.
* A pirate flag translates a message to English, then to pirate speak.
* See [Flags and diagnostics](../commands/flags.md).

### User app
* The bot can be **installed on your Discord account**: `/translate`, `/detect`, `/languages`, `/help`, `/invite`, `/dashboard`, `/support` and the **Translate** and **Detect** menus then work in servers where the bot is not added, in DMs and in group chats.
* Two personal settings on the dashboard [Account page](../website/dashboard/account.md): the **default language** and **public replies**. `/invite` has an **Add to my account** button.
* See [User app](../commands/user-app.md).

### Diagnostics
* `/check-permissions` lists the permissions the bot is missing in every configured channel and category, so "the bot does not translate" is answered in one command.

## Improvements

* **Typing indicator**: the bot shows "typing…" while a translation is prepared (channels, groups, categories, roles and flags). It is not shown where the bot cannot send the translation.
* **On/off switches**: each channel configuration has an *Enabled* toggle, and role and category configurations can be turned off without deleting them.
* **Language options** have autocomplete and accept the name or the ISO code of a language.
* **`/help`** was rewritten and lists all the commands. The welcome message has a **Support** button next to the dashboard and top.gg buttons.
* The bot no longer asks for the **Server Members** intent: fewer permissions, more privacy.
* A **vote reminder** is posted at most once a day when voice features are used without a vote or Premium.
* One single Premium link everywhere (bot and website).

## Dashboard and website

* New pages: **Translation Groups**, **FAQ**, **Speech to text**, **Text to speech** and **Flag shortcuts**. Everything above can be configured from the [dashboard](../website/dashboard/README.md).
* Members with the **Manage Server** permission can configure the bot, not only administrators. The list of your servers updates itself.
* **Free / Premium comparison table** in the dashboard and a public **Premium page**.
* **Premium refresh button**: after subscribing, no need to wait for the next synchronisation (a short cooldown applies).
* New **status page** for the bot and the translation services.
* Select lists have a search field, and menus close when you click outside.
* Public pages load faster (pre-rendered) and have better titles and descriptions for search engines.
* Updated terms of use, privacy policy, refund policy and legal notice.

## Translation engine and API

* Translations now run on a **new translation API with better quality**, more natural and closer to how people really write. Premium servers get the best engine with priority.
* Discord formatting is kept: bold, italics, strikethrough, spoilers, code blocks, quotes, lists, mentions, emojis and links.
* Brand names (Discord, Interaction Bot, Patreon…) are no longer translated.
* Repeated translations are cached, and identical requests are grouped.
* Speech recognition and speech synthesis (52 languages) run on the same API.

## Fixes

* Translate menu: unsupported language and empty answers.
* Detect: users without an avatar.
* `/tts`: stale voice connection, and the second message of a TTS channel being lost.
* Translations of a category without a target channel are sent in the original channel.
* Language options of the FAQ commands no longer answer "unsupported language" for valid languages.
* Dashboard: a newly added server appears without waiting.

## Security and reliability

* Security hardening: messages can no longer be sent across servers, and the bot owner tools are opt-in.
* Limits on the length and number of simultaneous voice requests, and an anti-flood protection per server.
* Updated to the latest Python and Discord library versions.
* Monitoring of the bot and the API.
