## What is Interaction Bot?

Interaction Bot is a Discord bot that **breaks language barriers** on your server. Everything is set up from a [web dashboard](website/dashboard/README.md), or by talking to the [AI setup](management/ai-setup.md) in a channel (`/ai setup`). There is no configuration command to learn.

| Feature                  | What it does                                                                                       | Where                                         |
| ------------------------ | -------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| **Translation**          | 100 languages: commands, menus, flag reactions and automatic translation by channel, role, category or server | [Translation](translation/overview.md)        |
| **Language detection**   | Recognizes the language of a message, from the last messages of its author                          | [Detection](translation/language-detection.md) |
| **Text to speech**       | The bot reads the messages of a channel aloud in a voice channel, by rules (channel, category, server) | [Audio](audio/overview.md)                 |
| **Speech to text**       | Live transcription of a voice channel, with optional translation                                    | [Audio](audio/overview.md)                 |
| **FAQ**                  | Answers to your members' questions, on demand or automatic, in any language                         | [Q&A](qa/overview.md)                      |
| **Voice recording**      | One track per speaker, announced in the channel, with a page to listen and download                   | [Recording](audio/recording.md)               |
| **Temp voice**           | Members create their own temporary voice channels, with a control panel                              | [Temp voice](audio/tempvoice.md)              |
| **Live transcription**   | A Discord Activity that shows the transcription live; on Premium servers, the lines can be translated into the language of each viewer | [Activity](audio/live-transcription.md)       |
| **Voice cloning**        | Read messages with a voice created from your own voice (Premium)                                     | [Voices](audio/voices-and-cloning.md)         |
| **Quick setup**          | A guided page of the dashboard that sets the main modules in about a minute                          | [Quick setup](management/quick-setup.md)      |
| **Welcome and goodbye**  | Welcome, goodbye and private messages with banners, and roles given on arrival                       | [Welcome](management/welcome-and-goodbye.md)  |
| **Invite tracker**       | Who invited whom, a ranking of inviters and fake account detection                                   | [Invites](management/invite-tracker.md)       |
| **Honeypot**             | Trap channels that catch spam bots and punish them at once                                           | [Honeypot](management/honeypot.md)            |
| **Reaction roles**       | Panels where members get and drop their roles themselves                                             | [Reaction roles](management/reaction-roles.md) |
| **Event log**            | Edited and deleted messages, joins, leaves, roles, moderation and more, written to the channels you choose | [Event log](management/event-log.md)      |
| **Bot profile**          | The nickname, avatar, banner and bio of the bot on your server only (Premium)                        | [Bot profile](management/bot-profile.md)      |
| **AI setup**             | Configure the bot by talking to an AI, in a channel (`/ai setup`) or on the dashboard                | [AI setup](management/ai-setup.md)            |
| **Voice messages**       | Transcribe, translate and dub Discord voice messages                                                 | [Voice messages](audio/voice-messages.md)     |
| **Premium**              | Higher limits and extra options                                                                     | [Premium](premium/premium.md)                 |

New here? Start with [Getting started](getting-started.md). The questions that come back most often are in the [FAQ](faq.md). How the bot handles your data is in [Security and privacy](security.md), and the permissions it asks for are in [Permissions](permissions.md). What changed lately: [Changelogs](changelogs/README.md).

### How to read this documentation

* A slash command and its arguments are written like this: <mark style="color:green;">`/test arg1 [arg2 optional]`</mark>. `<arg>` is required, `[arg]` is optional. The full list is in [All commands](commands/all-commands.md).
* A role is written @role and a channel #channel.
* The **Translation** section explains how the translation works, the **Website** section describes the dashboard page by page, the **Audio** and **Q&A** sections cover voice and the FAQ, the **Server management** section covers the welcome messages, the invite tracker, the honeypot, the reaction roles, the bot profile, the event log and the setup pages, and **Premium** explains the offers.
