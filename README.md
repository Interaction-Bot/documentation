## What is Interaction Bot?

Interaction Bot is a Discord bot that **breaks language barriers** on your server, with a [web dashboard](website/dashboard/) to configure everything.

| Feature                  | What it does                                                                                       | Where                                         |
| ------------------------ | -------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| **Translation**          | 100 languages: commands, menus, flag reactions and automatic translation by channel, role, category or group | [Translation](translation/overview.md)        |
| **Language detection**   | Recognizes the language of a message, tunable per channel                                           | [Detection](translation/language-detection.md) |
| **Text to speech**       | The bot reads text in a voice channel, or the messages of a channel                                 | [Audio](audio/overview.md)                 |
| **Speech to text**       | Live transcription of a voice channel, with optional translation                                    | [Audio](audio/overview.md)                 |
| **FAQ**                  | Answers to your members' questions, on demand or automatic, in any language                         | [Q&A](qa/overview.md)                      |
| **Premium**              | Higher limits and extra options                                                                     | [Premium](premium/premium.md)                 |

New here? Start with [Getting started](getting-started.md). What changed lately: [Changelogs](changelogs/README.md).

### How to read this documentation

* A slash command and its arguments are written like this: <mark style="color:green;">`/test arg1 [arg2 optional]`</mark>. `<arg>` is required, `[arg]` is optional.
* A role is written @role and a channel #channel.
* The **Translation** section explains how the translation works, the **Website** section describes the dashboard, the **Audio** and **Q&A** sections cover voice and the FAQ, the **Commands** section lists every command and **Premium** explains the offers.
