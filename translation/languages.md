# Languages and flags

Interaction Bot translates **100 languages**. The source language is detected automatically, you only choose the **target** language.

In Discord, `/languages` shows the same list.

## Flags

Flag translation understands **171 flag emojis**. A flag stands for the main language chosen for the country, for example 🇫🇷 gives French, 🇬🇧, 🇺🇸 and 🇨🇦 give English, 🇧🇷 and 🇵🇹 give Portuguese, 🇨🇭 gives German and 🇧🇪 gives Dutch.

Special flags:

* 🏴‍☠️ **Pirate flag**: the message is translated in English, then written in pirate speech.
* 🇮🇱 **Israel**: Hebrew.

{% hint style="info" %}
If a flag does nothing, check that flag translation is not disabled for the channel in [Flag translation](../website/dashboard/flag-translation.md).
{% endhint %}
