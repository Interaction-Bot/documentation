# Language identification

The bot detects the language of each message before translating it. Short messages are harder to identify, so this page lets you choose, for a channel, the **minimum number of characters** a message must have to be translated automatically.

Click on _**Add a channel**_, choose:

* _**CHANNEL**_: the channel where the configuration applies.
* _**MINIMUM CHARACTER**_: the minimum number of characters for a message to be translated.

Increasing this value reduces mistakes caused by very short messages (see also the [FAQ](../../faq.md)). Save your changes when you are done.
