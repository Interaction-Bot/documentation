# Blacklist

{% hint style="warning" %}
The blacklist is a **premium** feature.
{% endhint %}

The page has three sections:

* **Blacklist Channel**: a channel that will not be translated by role and category translation.
* **Blacklist Language**: a language that will not be translated when the bot detects it in a new message. Useful when a language is often confused with another one.
* **Blacklist Role**: a role whose messages will not be translated.

Click on _**Add**_ in the section, select the channel, language or role, then save.
