# Feature pages

The **Features** menu of the website (`interaction-bot.com/features`) opens one public page per feature of the bot. No login is needed. Each page explains what the feature does, how to start in three steps, the commands to use, the **limits of the Free and Premium plans**, and a button to configure it on the [dashboard](dashboard/README.md).

| Page | What it presents | Documentation |
| --- | --- | --- |
| Translation | Automatic and on-demand translation in 100+ languages | [Translation](../translation/overview.md) |
| FAQ and Q&A | A FAQ that answers members, on demand or automatically | [FAQ and /ask](../qa/faq.md) |
| Speech to text | Live transcription of voice channels | [Voice](../audio/voice.md) |
| Text to speech | Messages and channels read aloud | [Voice](../audio/voice.md), [Voices and cloning](../audio/voices-and-cloning.md) |
| Recording | Voice channel recordings, one track per speaker | [Voice recording](../audio/recording.md) |
| Temp voice | Temporary voice channels created by members | [Temporary voice channels](../audio/tempvoice.md) |
| User app | The bot installed on your own Discord account | [User app](../commands/user-app.md) |
| Activity | The live transcription inside Discord | [Live transcription](../audio/live-transcription.md) |

The list of commands is on the [Commands page](commands.md), and the state of the services on the [Status page](status.md).
